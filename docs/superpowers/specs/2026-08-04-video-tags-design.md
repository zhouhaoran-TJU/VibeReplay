# 视频标签设计

## 目标

为当前播放的视频添加或编辑多个标签。用户既可以输入新标签，也可以从所有已保存视频形成的历史标签中勾选；通过播放器顶部的“标签”入口按标签浏览视频，并以筛选结果作为播放队列。

## 交互

- “操作”菜单新增“编辑当前视频标签”。没有当前视频时给出提示。
- 编辑对话框顶部提供文本输入，支持用中英文逗号或换行分隔多个新标签；下方列出历史标签，当前视频已有标签默认勾选。
- 保存时合并输入和勾选项，忽略空白并按大小写不敏感去重；全部清空表示移除当前视频的标签记录。
- “浏览”菜单新增“按标签浏览”。点击后先选择标签，再展示匹配视频；点击视频后按当前筛选顺序建立播放队列。
- 删除视频成功后同步清除其标签记录，避免标签列表保留失效文件。

## 数据与边界

标签数据沿用应用现有 `SharedPreferences + JSON` 方案，单独存入 `tagged_videos`。每条记录保存稳定来源键、标题、路径、Shizuku/content URI 标记和标签数组，可覆盖普通文件、Shizuku 文件和系统文件选择器 URI。标签历史只由仍有标签的视频生成，不另存一份易失配的历史表。

## 验证与发布

- 纯 Java 单元测试覆盖标签合并、去重、更新/删除、历史汇总和筛选顺序。
- 运行完整单测并构建 debug、beta APK。
- 版本升级为 `3.8` / `29`，更新 README、发布 APK、哈希、大小和更新说明，并提交推送到现有 `origin/main`。
